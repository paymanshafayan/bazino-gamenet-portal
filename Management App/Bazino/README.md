## 🚀 اجرای محلی

**پیش‌نیاز:** Node.js

```bash
npm install
npm run dev
```

## 🔧 بیلد

```bash
npm run build
```

خروجی در پوشه `dist/` قرار می‌گیرد و وب‌سایت بازینو آن را در مسیر `/management-app/` سرو می‌کند.

## 🔑 تنظیمات

| متغیر | توضیح |
|---|---|
| `GEMINI_API_KEY` | کلید API گوگل جمینای (برای قابلیت‌های هوش مصنوعی) |
| `APP_URL` | آدرس عمومی میزبانی برنامه |
