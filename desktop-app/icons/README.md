# آیکون‌های لازم

این پوشه خالیه چون نمی‌شه فایل باینری آیکون (`.ico`/`.icns`) رو در یک محیط متنی ساخت. قبل از `npm run dist`، این سه فایل رو اینجا اضافه کنید (یا خطوط `icon` مربوطه رو از `package.json` بردارید تا الکترون از آیکون پیش‌فرض خودش استفاده کنه — برای اولین build آزمایشی کافیه):

| فایل | برای | حداقل سایز |
|---|---|---|
| `icon.ico` | ویندوز | ۲۵۶×۲۵۶ (چندرزولوشنی، شامل ۱۶/۳۲/۴۸/۲۵۶) |
| `icon.icns` | مک | ۱۰۲۴×۱۰۲۴ (چندرزولوشنی) |
| `icon.png` | لینوکس | ۵۱۲×۵۱۲ |

ساده‌ترین راه: یک لوگوی PNG مربعی ۱۰۲۴×۱۰۲۴ بسازید، بعد با ابزار رایگان [electron-icon-builder](https://www.npmjs.com/package/electron-icon-builder) هر سه فرمت رو خودکار ازش تولید کنید:
```bash
npx electron-icon-builder --input=logo-1024.png --output=./
```
