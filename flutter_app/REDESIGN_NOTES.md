# یادداشت‌های ری‌دیزاین بصری (Neon Glass Gaming) — اپ فلاتر

کاربر از ظاهر «ارزون/تمپلیتی» اپ فلاتر ناراضی بود و دو تصویر مرجع (سبک "PathMD" — کارت‌های شیشه‌ای نئونی، هگزاگون، نمودار رادار) فرستاد. تصمیم گرفته شد:
- فقط **اپ فلاتر** ری‌دیزاین بشه (نه سایت، نه Management App).
- فلاتر عوض نشه به React Native (بحث کامل در چت — تفاوت ظاهری ربطی به فریم‌ورک نداشت).
- تصویر ۱ (PathMD) به‌عنوان مرجع اصلی انتخاب شد (نه تصویر ۲ که حس عمومی AI-SaaS داشت، نه گیمینگ).
- پالت رنگی: **سایان + بنفش** (نه فقط سایان) — چون `secondary = Color(0xFF9D00FF)` از قبل در تم فلاتر به‌عنوان رنگ ثانویه تعریف شده بود؛ قانون «بدون بنفش» که در حافظه ثبت شده بود مربوط به یک تصمیم قدیمی‌تر (احتمالاً برای سایت) بود، نه این اپ.

## ⚠️ کاملاً تست‌نشده
این sandbox هیچ Flutter SDK/emulator/device واقعی‌ای نداشت — فقط یک بررسی دستی و یک اسکریپت پایتون برای شمارش تعادل پرانتز/آکولاد/براکت (نه یک syntax check واقعی) انجام شد. **قبل از هر استفاده‌ای، حتماً `flutter analyze` و `flutter run` رو روی یک دستگاه/امولاتور واقعی اجرا کنید.**

## چه چیزی تغییر کرد

### `lib/theme.dart` — بازنویسی کامل (سیستم طراحی جدید)
- پالت: `darkBg`/`darkBgSecondary` (گرادیان پس‌زمینه‌ی بنفش تیره به مشکی)، `primary` (سایان نئون)، `secondary` (بنفش نئون)، `goldAccent`.
- **یک باگ واقعی رفع شد:** `GamingTheme.darkBackground` در `main.dart` و `auth_screen.dart` استفاده می‌شد ولی هیچ‌جا تعریف نشده بود (فقط `darkBg` تعریف شده بود) — یعنی این پروژه در حالت فعلی‌اش **اصلاً کامپایل نمی‌شد**! به‌عنوان یک alias (`static const darkBackground = darkBg`) رفع شد.
- ویجت‌های جدید قابل‌استفاده در همه‌ی صفحات:
  - `GlassCard` — کارت شیشه‌ای (blur واقعی با `BackdropFilter`/`ImageFilter.blur`، بدون نیاز به پکیج جدید) + بردر با گلو.
  - `NeonGradientButton` — دکمه‌ی CTA تمام‌عرض با گرادیان سایان→بنفش (مثل دکمه‌ی "Get Started" تصویر مرجع).
  - `HexagonBadge` — نشان هگزاگونی با گلو (لوگو/آیکون‌های برند)، با `CustomPainter` دستی رسم شده (بدون نیاز به asset تصویری).
  - `CircuitBackgroundPainter` — الگوی خط مداری کم‌رنگ برای پس‌زمینه‌ی splash (تقریب ایستا از پس‌زمینه‌ی تصویر مرجع).

### `lib/main.dart`
صفحه‌ی splash/bootstrapping بازطراحی شد: گرادیان پس‌زمینه + `CircuitBackgroundPainter` + `HexagonBadge` لوگو + عنوان با گرادیان متنی (`ShaderMask`).

### `lib/screens/auth_screen.dart`
پس‌زمینه‌ی گرادیانی + `HexagonBadge` به‌جای آیکون ساده + فرم داخل `GlassCard` + `NeonGradientButton` برای دکمه‌ی اصلی. **منطق فرم (validators، submit، state) عیناً دست‌نخورده موند** — فقط پوسته‌ی بصری عوض شد.

### `lib/screens/hub_screen.dart`
- نوار پایین (bottom nav): پس‌زمینه‌ی شیشه‌ای واقعی (`BackdropFilter` blur) + بردر گلودار، به‌جای پس‌زمینه‌ی مشکی تخت. **آیتم‌ها/منطق ناوبری دست‌نخورده موند.**
- دکمه‌ی شناور Jarvis: از یک FAB مربعی به یک `HexagonBadge` با گلو قوی تبدیل شد (شبیه دکمه‌ی لوزی شناور تصویر مرجع).
- AppBar: پس‌زمینه‌ی شیشه‌ای (blur) به‌جای مشکی نیمه‌شفاف تخت.
- کل بدنه‌ی صفحه (`Scaffold.body`) گرادیان پس‌زمینه‌ی جدید رو گرفت — یعنی همه‌ی ۶ تب (خانه/رزرو/کافه/فروشگاه/مسابقات/باشگاه) خودکار پس‌زمینه‌ی جدید رو می‌گیرن، حتی بدون تغییر مستقیم توی خودشون.

## چه چیزی *تغییر نکرد* (خارج از اسکوپ این نشست)

صفحات زیر هنوز از استایل قدیمی‌تر (فلت، بدون glassmorphism) استفاده می‌کنن — چون تغییر همه‌چیز در یک نشست بدون امکان تست بصری ریسک خیلی بالایی داشت:
- `messages_screen.dart` (قبلاً هم Card+shape مناسب داشت، فقط رنگش عوض شد)
- `jarvis_assistant.dart` (هیچ Card/ElevatedButton نداره؛ رابط کاربری‌اش با CustomPainter ساخته شده و از قبل رنگ‌های تم رو می‌گیره)
- `home_screen.dart` (⚠️ **این فایل کاملاً death code است** — هیچ‌جا import/استفاده نمی‌شه، دست‌نخورده موند)

**خبر خوب:** چون این صفحات از `GamingTheme.primary`/`secondary`/`darkCard` و غیره استفاده می‌کنن (نه رنگ‌های هاردکد جدا)، با تغییر پالت در `theme.dart`، رنگ‌بندی‌شون تا حدی خودکار به‌روز شده.

### کار بعدی پیشنهادی (اگه خواستید ادامه بدید)
برای هر کدوم از صفحات بالا، جایگزین کردن `Container`/`Card`های ساده با `GlassCard`، و دکمه‌های اصلی با `NeonGradientButton`، باید به‌سرعت همون حس بصری رو به کل اپ تعمیم بده — چون زیرساختش (`theme.dart`) از قبل آماده‌ست.

## نکته‌ی جانبی مهم
`lib/screens/home_screen.dart` (فایل جدا، نه `_buildHomeSlider` داخل `hub_screen.dart`) **کاملاً death code است** — هیچ‌جا import/استفاده نمی‌شه (`hub_screen.dart` منطق home خودش رو مستقل داره). این نشست دست‌نخورده موند (خارج از اسکوپ درخواست فعلی)، ولی موقع پاکسازی بعدی پروژه قابل‌حذفه.

## پاس دوم (نشست بعدی): رفع دکمه‌ها و پنل‌های «کلاسیک/بیضی‌مانند»

کاربر بعد از دیدن نتیجه‌ی پاس اول، گفت رنگ‌بندی خوبه ولی دکمه‌ها/پنل‌ها هنوز شکل قدیمی (گرد/بیضی) دارن و باید شبیه تصویر مرجع بشن. بررسی دقیق نشون داد: مشکل چندان به مقدار عددی `borderRadius` مربوط نبود (اکثراً بین ۶ تا ۲۴ پیکسل، معقول)، بلکه به این برمی‌گشت که ۹ صفحه‌ی باقی‌مونده هنوز از `ElevatedButton`/`Card` معمولی Material استفاده می‌کردن (بدون گرادیان/گلو/شیشه‌ای بودن) — و چون `useMaterial3: true` در `theme.dart` ست شده، هر `ElevatedButton` بدون `shape` صریح، پیش‌فرض بسیار گرد/pill-مانند Material 3 رو می‌گرفت.

### فایل‌هایی که در این پاس به‌روزرسانی شدن
- **`cafe_screen.dart`**: بنر معرفی + کارت‌های آیتم منو → `GlassCard`؛ دکمه‌ی «افزودن به سبد» و «ثبت نهایی سفارش» → گرادیان (`NeonGradientButton`/دکمه‌ی گرادیانی کوچک)؛ نوار پایین سبد خرید → پس‌زمینه‌ی شیشه‌ای واقعی (blur).
- **`shop_screen.dart`**: بنر معرفی + کارت‌های محصول → `GlassCard`؛ دکمه‌ی «خرید فوری» → `NeonGradientButton`.
- **`reservation_screen.dart`**: بنر معرفی + پنل فاکتور/تسویه‌حساب → `GlassCard`؛ دکمه‌ی «اعمال» کد تخفیف → گرادیان کوچک؛ دکمه‌ی «پرداخت نهایی» → `NeonGradientButton`.
- **`tournament_screen.dart`**: بنر معرفی + کارت هر تورنمنت → `GlassCard`؛ دکمه‌ی «ثبت‌نام تیم» → `NeonGradientButton`؛ دکمه‌ی «تایید نهایی» داخل دیالوگ (که اصلاً `shape` نداشت — همون باگی که Dart analyzer قبلاً گزارش داده بود) → گرادیان + شکل مشخص.
- **`loyalty_screen.dart`**: پنل خلاصه‌ی امتیاز + پنل تبدیل امتیاز + کارت‌های کد تخفیف + جدول تراکنش‌ها → همه `GlassCard`؛ دکمه‌ی «تبدیل امتیاز» → `NeonGradientButton`.
- **`chat_screen.dart`**: دکمه‌ی ورود/عضویت (صفحه‌ی مهمان) → `NeonGradientButton`.
- **`blog_screen.dart`**: کارت هر مقاله → `GlassCard` با تصویر کاور گوشه‌گرد.

### تست انجام‌شده
esbuild برای Dart واقعاً کار نمی‌کنه (فقط JS/TS رو می‌فهمه)؛ به‌جاش بعد از **هر** ویرایش، یک اسکریپت پایتون بالانس پرانتز/آکولاد/براکت رو چک کرد (نه یک syntax check واقعی Dart) — همه‌ی فایل‌ها بالانس تأیید شدن. **هنوز `flutter analyze`/`flutter run` واقعی روی این تغییرات اجرا نشده.**
