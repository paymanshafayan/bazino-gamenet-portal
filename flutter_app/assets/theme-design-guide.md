# راهنمای جامع طراحی و نصب قالب (تم) در پرتال گیم‌نت و اپلیکیشن فلاتر
======================================================================

این راهنما برای مدیران سیستم، طراحان و توسعه‌دهندگان آماده شده تا بتوانند قالب‌های بصری جدید و منطبق بر استانداردهای زیبایی‌شناسی سالن‌های بازی مدرن (سایبرپانک، کلاسیک، نئونی) را طراحی، درون‌ریزی و در لحظه اعمال کنند.

---

## ۱. ساختار متغیرهای رنگی (Color Variables)

در سیستم طراحی پرتال، رنگ‌ها بر اساس متغیرهای ریشه CSS (Custom CSS Properties) تعریف شده‌اند که به صورت خودکار با پایگاه‌داده و کلاینت‌ها (از جمله اپلیکیشن Flutter) همگام‌سازی می‌شوند. این متغیرها به شرح زیر هستند:

| نام متغیر سیستم | نام کلید JSON | کارکرد و حوزه اعمال در پورتال | نمونه پیش‌فرض (سایبرپانک) |
| :--- | :--- | :--- | :--- |
| `--primary-color` | `primaryColor` | رنگ اصلی (Accent) سالن؛ دکمه‌ها، درخشش‌های نئونی، متون کلیدی | `#1BC2CA` (آبی فیروزه‌ای نئون) |
| `--primary-hover-color` | `primaryHover` | رنگ حالت هاور دکمه‌ها و تعاملات کلیکی | `#159DA4` (فیروزه‌ای تیره) |
| `--dark-bg-color` | `darkBg` | رنگ پس‌زمینه کل پورتال (صفحه اصلی و بدنه) | `#0B1125` (سرمه‌ای تاریک) |
| `--dark-card-color` | `darkCard` | رنگ پس‌زمینه کارتها، پنل‌ها، فیلدهای ورودی و مودال‌ها | `#292845` (سورمه‌ای-بنفش کدر) |
| `--accent-red-color` | `accentRed` | رنگ هشدار، دکمه‌های لغو و حاشیه‌های نئونی فرعی | `#FF3B30` (سرخ نئونی) |

---

## ۲. فرمت استاندارد درون‌ریزی (Import Schema)

هر قالب جدید به صورت یک شیء ساختاریافته JSON در دیتابیس ثبت می‌شود. اگر قصد دارید تم جدیدی طراحی و نصب کنید، پالت رنگی خود را در قالب ساختار زیر تنظیم نمایید:

```json
{
  "name": "نام فارسی تم (مثال: بنفش جادویی)",
  "nameEn": "Magic Violet",
  "primaryColor": "#A855F7",
  "primaryHover": "#9333EA",
  "darkBg": "#090514",
  "darkCard": "#1E152A",
  "accentRed": "#EF4444"
}
```

## ۳. پالت‌های رنگی پیشنهادی و جذاب برای سالن گیم‌نت

### الف) پالت سایبرپانک آبی (Cyberpunk Cyan) - فعال پیش‌فرض
* **رنگ اصلی (Accent):** `#1BC2CA` (نیون سایان)
* **پس‌زمینه (Bg):** `#0B1125` (سرمه‌ای کهکشانی)
* **کارت‌ها (Card):** `#292845` (بنفش ملایم کدر)

### ب) پالت طلایی ذغالی (Dark Gold / Obsidian) - کلاسیک مجلل
* **رنگ اصلی (Accent):** `#FFB800` (طلایی غنی)
* **پس‌زمینه (Bg):** `#07080A` (مشکی مطلق براق)
* **کارت‌ها (Card):** `#12141C` (دودی تیره)

### ج) پالت جنگل زمردی (Emerald Green / Matrix) - هکری ماتریکسی
* **رنگ اصلی (Accent):** `#10B981` (سبز فسفری زمردی)
* **پس‌زمینه (Bg):** `#060F0E` (سبز یشمی فوق تیره)
* **کارت‌ها (Card):** `#0F1E1C` (یشمی دودی)

### د) پالت سرخ خونین (Crimson Rage) - مخصوص بازی‌های اکشن و شوتر
* **رنگ اصلی (Accent):** `#EF4444` (قرمز نئونی زنده)
* **پس‌زمینه (Bg):** `#0E0808` (مشکی مایل به قهوه‌ای گرم)
* **کارت‌ها (Card):** `#1F1111` (آجری تیره)

## ۴. نحوه اعمال تم در اپلیکیشن فلاتر (Flutter App Setup)

در فایل `theme.dart` اپلیکیشن فلاتر، تم سیستم به کلاس `GamingTheme` نگاشت شده است. هنگام نصب تم در سرور، پالت رنگی به کلاینت فلاتر ارسال شده و با تعریف زیر همگام می‌شود:

```dart
class GamingTheme {
  static const Color darkBg = Color(0xFF0B1125); // مقدار پس‌زمینه تم انتخابی
  static const Color darkCard = Color(0xFF292845); // مقدار کارت تم انتخابی
  static const Color primary = Color(0xFF1BC2CA); // مقدار رنگ اکسنت اصلی
  static const Color primaryHover = Color(0xFF159DA4);
  ...
}
```
فونت فارسی استفاده شده در کل اپلیکیشن فلاتر و پورتال وب، فونت ملی و بهینه **«وزیری» (Vazirmatn)** می‌باشد که بیشترین خوانایی را در نمایشگرهای موبایل و سیستم‌های گیمینگ دارد.

---

## ۵. راهنمای گام به گام نصب تم جدید از پنل مدیریت

۱. به **پنل مدیریت سالن** مراجعه کنید.
۲. بر روی تب **«تم‌ها و قالب‌های سایت»** کلیک کنید.
۳. در فرم **«نصب و درون‌ریزی قالب جدید»**، نام فارسی و انگلیسی مورد نظرتان را وارد کنید.
۴. رنگ‌های دلخواه خود را با قطره‌چکان انتخاب کنید یا کدهای Hex بالا را به صورت دستی تایپ کنید.
۵. دکمه **«نصب و افزودن قالب جدید»** را فشار دهید.
۶. قالب جدید بلافاصله در لیست تم‌های بالا ظاهر می‌شود. با کلیک روی **«فعال‌سازی سریع قالب»**، کل ظاهر سالن به رنگ جدید تغییر حالت می‌دهد.
