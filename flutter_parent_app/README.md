# BAZINO Parent App - اپلیکیشن والدین

اپلیکیشن اختصاصی والدین برای نظارت بر حضور و فعالیت فرزندان در محیط BAZINO.

## قابلیت‌های کلیدی

### 1. داشبورد نظارت لحظه‌ای
- نمایش وضعیت فعلی فرزند: داخل گیم‌نت / خارج / در حال بازی
- ایستگاه فعلی، بازی در حال اجرا، زمان سپری شده
- اعلان ورود/خروج خودکار

### 2. تایید درخواست‌های فرزند (Approval Flow)
قبل از نهایی شدن، این درخواست‌ها برای والد ارسال می‌شود:

- **رزرو ایستگاه** - انتخاب PC/PS5، زمان، تعرفه
- **شرکت در مسابقات** - تورنمنت، تیم، هزینه ورودی
- **انتخاب بازی** - نام بازی، رده سنی، مدت زمان
- **سفارش از بوفه** - آیتم‌ها، مبلغ، یادداشت

والد می‌تواند:
- ✅ تایید کند (با یادداشت اختیاری)
- ❌ رد کند (با دلیل)
- ⏰ تایید مشروط (مثلا فقط 1 ساعت)

### 3. تاریخچه فعالیت
- تمام رزروها، سفارش‌ها، مسابقات با وضعیت تایید
- نمودار هفتگی زمان بازی و هزینه
- فیلتر بر اساس نوع فعالیت و تاریخ

### 4. کنترل‌ها و محدودیت‌ها
- سقف زمانی روزانه/هفتگی
- سقف هزینه روزانه
- لیست بازی‌های مجاز / غیرمجاز بر اساس رده سنی
- ساعات مجاز حضور (مثلا 14:00 تا 21:00)
- اعلان خودکار در صورت تخطی

### 5. پروفایل فرزند
- اطلاعات، سطح وفاداری، امتیاز
- لینک کردن چند فرزند به یک والد
- گزارش ماهانه

## API های مورد نیاز (بک‌اند)

```
GET    /api/parent/children              # لیست فرزندان
POST   /api/parent/link-child            # لینک فرزند جدید (کد دعوت یا نام کاربری)
GET    /api/parent/children/:id/status   # وضعیت لحظه‌ای
GET    /api/parent/requests              # درخواست‌های در انتظار تایید
POST   /api/parent/requests/:id/approve  # تایید
POST   /api/parent/requests/:id/reject   # رد
GET    /api/parent/activity/:childId     # تاریخچه
GET    /api/parent/settings/:childId     # محدودیت‌ها
PUT    /api/parent/settings/:childId     # بروزرسانی محدودیت‌ها
```

## اجرا

```bash
cd flutter_parent_app
flutter pub get
flutter run --dart-define=API_BASE_URL=https://bazino.pro
# یا لوکال:
flutter run --dart-define=API_BASE_URL=http://localhost:3000
```

## تفاوت با اپ اصلی

| اپ کاربر (بازینو) | اپ والدین (بازینو والد) |
|---|---|
| تم نئون سایبرپانک (سایان/بنفش) | تم آرام والدین (آبی/سفید/سبز) |
| رزرو مستقیم | تایید رزرو فرزند |
| خرید مستقیم | تایید خرید فرزند |
| امتیاز و وفاداری خود | نظارت بر امتیاز فرزند |

## امنیت

- توکن JWT والدین جدا از فرزند
- هر درخواست فرزند یک `parentApprovalId` دارد
- بدون تایید والد، رزرو/سفارش در سرور نهایی نمی‌شود
- والد فقط فرزندان لینک‌شده خودش را می‌بیند
