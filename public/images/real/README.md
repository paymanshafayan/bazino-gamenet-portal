# تصاویر واقعی گیم‌نت بازینو

تصاویر واقعی سالن، سیستم‌ها، کافه، فروشگاه و … را در همین پوشه آپلود کنید.
در مرحله‌ی بعد، تصاویر نمونه‌ی سایت (`public/images/home/*`, اسلایدر، کارت‌ها) با این تصاویر جایگزین می‌شوند.

## راهنما
- فرمت: JPG / PNG / WebP (WebP ترجیح دارد). حجم هر فایل ترجیحاً < 2MB؛ عرض ≥ 1600px برای بنر/هرو.
- نام‌گذاری پیشنهادی (لاتین، بدون فاصله) تا جایگزینی سریع‌تر باشد:

| نام فایل | محل استفاده |
|---|---|
| `hero-1.jpg`, `hero-2.jpg`, … | اسلایدر/هرو صفحه اصلی (افقی 21:9 یا 16:9) |
| `lounge-main.jpg` | سالن اصلی |
| `lounge-vip.jpg` | اتاق VIP |
| `pc-station.jpg` | سیستم‌های PC |
| `console-zone.jpg` | زون کنسول (PS5/Xbox) |
| `cafe-1.jpg`, `cafe-2.jpg` | کافه / بوفه |
| `shop-1.jpg` | فروشگاه لوازم جانبی |
| `tournament-1.jpg` | مسابقات / رویدادها |
| `exterior.jpg` | نمای بیرونی / ورودی (Vista Mare) |
| `team-*.jpg` | کادر / مربیان |
| `logo.png` | لوگو با پس‌زمینه‌ی شفاف (اگر نسخه‌ی جدید دارید) |

نام‌های دیگر هم مشکلی ندارد؛ فقط در پیام بعدی بگویید هر تصویر مربوط به کجاست.
