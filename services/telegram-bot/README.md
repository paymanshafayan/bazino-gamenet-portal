# Bazino Telegram Bot (BotFather bot — بدون وابستگی)

ربات عملیاتی کانال/گروه/جستجوی بازینو. فقط با Bot API رسمی تلگرام (بدون یوزربات/MTProto) — صددرصد مطابق قوانین تلگرام.

## قابلیت‌ها
| فرمان | کار |
|---|---|
| `/post متن` | انتشار متن در کانال بازینو |
| `/photo کپشن` (ریپلای روی عکس) | انتشار عکس در کانال |
| `/announce متن` | ارسال به همهٔ گروه‌هایی که ربات در آن‌ها هست (با ضداسپم: سقف ۳ پست در ۳ ساعت هر گروه + فاصلهٔ ۶۰ ثانیه) |
| `/groups` | لیست گروه‌ها |
| `/search واژه` | جستجوی ۷۲ ساعت اخیر کانال‌های عمومی پایش‌شده (t.me/s — بدون توکن) |
| `/watch` | آخرین برخوردخوردنهای کلیدواژههای گیمینگ |
| `/status` / `/id` / `/help` | سلامت / شناسه / راهنما |

**پایش پس‌زمینه:** هر ۱۵ دقیقه کانال‌های عمومی `kibrispostasi`، `haberkibriscom`، `northcyprusfaq` از پیش‌نمایش وب خوانده می‌شوند؛ پستهای دارای کلیدواژهٔ گیمینگ (turnuva، PS5، FIFA/FC، مسابقه، گیم، اسکله و…) و بازدید ≥۳۰۰ به مالک اعلان داده می‌شود.

## محدودیتهای صادقانه (قوانین تلگرام)
- باتها **نمیتوانند خودشان عضو گروه شوند** — هیچ API قانونی وجود ندارد؛ عضویت خودکار با اکانت کاربر (userbot) خلاف قوانین ضداسپم تلگرام است و حساب را به خطر میاندازد ⇒ ساخته نشد. مسیر درست: ادمین گروه، ربات را Add member میکند.
- جستجوی Bot API وجود ندارد ⇒ جستجو از صفحات عمومی وب t.me/s انجام میشود (فقط کانالهای عمومی).
- همهٔ فرمانها فقط برای مالک (`TG_OWNER_IDS`)؛ توکن هرگز لاگ نمیشود؛ خروجی HTML_escape میشود.

## راهاندازی
> **وضعیت (۲۰۲۶-۰۹-۱۴):** مراحل ۱ و ۲ انجام شده — ربات `@bazino_ops_bot` ساخته شد، در کانال `@bazino_pro` ادمین (فقط Post Messages) است و تست لایو پست موفق بود. فقط اجرای دائمی (مرحلهٔ ۳ یا ۴) باقی است.

### ۱) توکن از BotFather (۲ دقیقه)
در تلگرام: `@BotFather` → `/newbot` → نام: `Bazino Ops Bot` → یوزرنیم: مثلاً `bazino_ops_bot` → توکن را کپی کنید (`123456:ABC-…`).

### ۲) دسترسیها
- **کانال:** کانال بازینو → Administrators → Add admin → ربات → فقط حق `Post Messages`.
- **گروهها:** در هر گروه → Add member → ربات (نیازی به ادمین نیست).

### ۳) اجرا (PowerShell)
```powershell
$env:TG_BOT_TOKEN='123456:ABC-DEF...'
$env:TG_OWNER_IDS='123456789'          # اگر نمیدانید: به ربات /start بدهید؛ همان پیام، id شما را میدهد
$env:TG_CHANNEL='@bazino_pro'          # یوزرنیم کانال بازینو
node services/telegram-bot/bot.mjs
```

### ۴) اجرای دائمی (Railway)
سرویس جدید از همین ریپو → **Root Directory:** `services/telegram-bot` (package.json با `npm start` موجود است) → متغیرها:

```
TG_BOT_TOKEN=89140475…        # از KEYS.md
TG_OWNER_IDS=8769056098
TG_CHANNEL=@bazino_pro
```

> راهنمای دیگر: بدون Root Directory هم کار میکند — Start Command: `node services/telegram-bot/bot.mjs` از ریشهٔ ریپو.

## متغیرها
| متغیر | الزامی | توضیح |
|---|---|---|
| `TG_BOT_TOKEN` | ✅ | توکن BotFather |
| `TG_OWNER_IDS` | ✅ | شناسههای عددی مالک (با کاما) |
| `TG_CHANNEL` | ✅ | یوزرنیم کانال برای /post و /photo (`@bazino_pro`) |
| `TG_WATCH_MIN` | — | بازهٔ پایش (پیشفرض ۱۵ دقیقه) |
| `TG_STATE_PATH` | — | مسیر فایل وضعیت (پیشفرض کنار bot.mjs) |

## تست
`npm test -- telegram-bot` — پارسر t.me/s (fixture)، محدودکنندهٔ ضداسپم، تطبیق کلیدواژه، فرمانها، escape.
