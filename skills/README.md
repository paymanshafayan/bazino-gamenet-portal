# 🧠 Skills — دانش قابل استفادهی مجدد پروژه بازینو

این پوشه «اسکیل»های پروژه است: هر زیرپوشه یک `SKILL.md` دارد که یک
گردشکار تکراری را قدمبهقدم (دستورات + نکتهها + معیار موفقیت) ثبت میکند.

## چطور استفاده میشود؟

- **جلسات آینده (هر AI یا توسعهدهنده):** قبل از انجام یک کار تکراری،
  `SKILL.md` مربوطه را بخوان و دقیقاً همان مراحل را دنبال کن.
- **بعد از هر تغییر بزرگ:** اگر گردشکار جدیدی را چند بار انجام دادی و
  به نتیجه رسیدی، آن را بهصورت یک SKILL.md جدید اینجا ثبت کن.

## فهرست

| Skill | کاربرد |
|---|---|
| [`verify-and-build`](verify-and-build/SKILL.md) | بررسی سلامت + بیلد کامل پروژه (lint, تست قالبها, vite build, باندل) |
| [`gtmetrix-performance`](gtmetrix-performance/SKILL.md) | رفع مشکلات عملکرد (باندل, تصاویر, فونت, lazy, کش) — معادل محلی GTmetrix |
| [`mirror-web-to-flutter`](mirror-web-to-flutter/SKILL.md) | mirror کردن تغییرات فرانتاند وب به `flutter_app/` |
| [`change-api-domain`](change-api-domain/SKILL.md) | تغییر دامنهی سرور API در کل پروژه (فلاتر + اپ مدیریت + اسناد) |

## قواعد

- هر `SKILL.md` باید: هدف، زمان استفاده، مراحل دقیق، دستورات واقعی، و
  «معیار موفقیت» داشته باشد.
- دستورات باید از روی وضعیت فعلی پروژه کپی شوند (نه حدس).
- اگر مرحلهای در عمل جواب نداد، SKILL.md را اصلاح کن — اسکیلها باید
  همیشه با کد همگام باشند.
