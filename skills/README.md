# مهارت‌های پروژه

این پوشه شامل مهارت‌های قابل‌استفاده برای بررسی و توسعه پروژه است. هر مهارت یک پوشه مستقل با دو فایل دارد:

- `SKILL.md`: دستورالعمل اجرایی و معیارهای پذیرش مهارت.
- `PROMPT.md`: پرامپت آماده برای فعال‌سازی مهارت در یک پروژه وب.

| مهارت | کاربرد |
| --- | --- |
| [`web-performance-optimizer`](./web-performance-optimizer/SKILL.md) | ممیزی، اولویت‌بندی و رفع مشکلات عملکرد وب مانند LCP، CLS، TBT، درخواست‌های third-party، cache، تصویر، فونت و JavaScript استفاده‌نشده. |
